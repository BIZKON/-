# ПряникПро - Калькулятор себестоимости пряников

Профессиональный калькулятор для расчета себестоимости кондитерских изделий с темной темой.

## Особенности

- 🌓 **Темная тема** - переключатель светлой/темной темы с сохранением в localStorage
- 🧮 **Расчет себестоимости** - полный расчет с учетом всех затрат
- 📊 **Аналитика** - детализация затрат и маржинальности
- 💼 **Лендинг страница** - красивая презентация сервиса
- 💳 **Страница оплаты** - форма подписки
- 📱 **Адаптивный дизайн** - работает на всех устройствах

## Установка

```bash
npm install
```

## Запуск

```bash
npm start
```

Приложение откроется в браузере по адресу [http://localhost:3000](http://localhost:3000)

## Технологии

- React 18
- Tailwind CSS
- Lucide React (иконки)

## Темная тема

Переключатель темы расположен в правом верхнем углу (иконка луны/солнца). Выбор темы сохраняется в localStorage браузера.
